# Customer Churn Intelligence System

**Tools:** SQL Server · Power BI · DAX  
**Dataset:** AdventureWorks2025 — 19,119 customers

## Business Problem
AdventureWorks has no visibility into which customers are about to leave.

## Key Results
- Identified $4M+ in revenue at risk from 5,369 high-churn-risk customers
- Segmented 19,119 customers into 3 risk tiers using RFM analysis
